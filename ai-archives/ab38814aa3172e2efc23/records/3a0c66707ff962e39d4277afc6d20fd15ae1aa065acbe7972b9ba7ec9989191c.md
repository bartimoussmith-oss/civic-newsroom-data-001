Purchase of Utility Rocket
Mr. Mayor
This is a request for a purchase order to buy the Utility Rocket.The Rocket is a
secure and reliable high-speedmobile communications gateway, to provide CP D with the
situational awareness theyneed on the frontline s.The Rocketis a secure broadband
appliance that provides a universal communications platform for any police, fire, or EMS
vehicle-leveraging one cellular data planfor all vehicle information communications
needs.The Rocket seamlessly interfaces with the latest generation of GPS, RFID and on-
board diagnostic and navigation mobile applications using hard-wired connections, or
WPA2wireless security with AES encryption.The system will eliminate the many
communication dead spots that exist in the City andpermit video data to be downloaded
from the police car to the server by a wireless means at fast speeds.The system will
track police vehicles by GPS on a map so that dispatchers know where each unit is,
improving officer safety while improving response times.
We are requesting this be placedon the October15,2012Finance Committee
agenda to expedite the installation as this will coincide with the installation of the
Arbitrator Camera System.This will reduce the cost of installation as they will be done
at the same time.
The Utility Company is a sole source for the Rocket.
Thank you for your consideration on this matter.
