EXHIBITA
Location.
The game machines will be placed on the south, north and east walls of the arcade space of the Ice
& Events Center.The Bubble hockey and Air hockey game machines will be located along the
north wall near the concessions area.
Maintenance: Service.
1.
Provider will keep all game machines clean and in working order at all times.
2.
If a game machine malfunctions, Ice&Event Center staff will contact Provider as soon as
possible and report the issue to ensure the game machines remain operable.
3.
If, at any time the Cityis displeased with a game machine or a game machine has constant
issues, the Citywill contact the Provider to discuss the options available for exchanging that
game machine for a different game machine.
4.
If a game machine needs moved to another area, Ice & Events Center staff will contact
Provider and make the necessary arrangements to have the game machine moved.
Collection of Cash: Revenue Distribution; Refunds.
1.
The cash will be emptied out ofa specific group ofgame machines every two tofour weeks.
Ice&Events Center staff may monitor this process. Coin meters in all game machines will
befully tracked and recorded each time a game machine is emptied.
2.
The revenue paid to the City will be 35% for new game machines and 40% for older game
machines.
3.
The revenue paid to the Provider will be 65% for new game machines and 60% for older
game machines.
4.
Ice&Events Center staff will maintain a list of refunds given to customersin theevent
game machines take the customer's money. The list will include which game machine did
not give the customer a credit for themoney inserted into the game machine.Ice &Events
Center staff shall usegood judgment when issuing refunds.
5.
Should any liquid get spilled on the Air hockey game machine, Ice&Events Center staff
shall insert$1.00 in the game machine to start the air blowing and immediately clean up the
spill. The $1.00 will be refunded to the Ice & Events Center.
Change Machine.
Provider will supply andmaintain a change machine to be located at the Ice& Events Center.Ifthe
change machine malfunctions, Ice & Events Center staff will contact the Provider as soon as
possible and report the issue to ensure the change machine remains operable.
