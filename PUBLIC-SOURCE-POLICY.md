# Public-record corpus policy

Include source records, not the owner's internal research or commentary. For this export, the input is restricted to already published generated representations under documents/ and meetings/ in the normalized collection. No repository-root Markdown research, private holdings, advocacy scripts, casework or media commentary is crawled. Public testimony contained within official meeting records remains part of the record and is not removed merely because the owner spoke.

The exporter does not independently inspect every source for classification accuracy and does not claim that path filtering alone proves a complete primary-source audit. Generated headers and extraction warnings are retained as representation metadata; original source boundaries and actual original/PDF checksums require further source reconciliation. No original binary files are copied by this exporter.

Published formats: exact UTF-8 Markdown representations; per-record JSON and CSV/JSONL catalogs; gzip full-text JSONL; typed document objects; literal identifier-reference spans in separate graph exports. Identifier mentions are not verified legal, financial, ownership or causal relationships. Dates, OCR and speaker attribution retain their uncertainty.

The copied text and structured exports are hosted in this new repository and remain readable without following links to an old repository. Provenance links may still identify the original source. No authentication or JavaScript is required for raw Markdown. Public availability does not guarantee that any particular model can fetch the files, ingest the entire corpus at once, train on it, or index it. The corpus is not claimed to be the complete historical archive until source-by-source coverage is reconciled.

Existing dataset versions are preserved. Exports are bounded by measured budgets; if a new host is needed, prepare its exact repository and publication scope for approval rather than deleting or truncating records.
